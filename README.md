# Task List Application

Простое приложение для работы со списком задач с backend на NestJS и frontend на React.

## Технологии

- Backend: NestJS
- Frontend: React, Material-UI, SCSS (БЭМ)
- HTTP клиент: axios

## Установка и запуск

### Backend

1. Перейдите в директорию `backend`:
   ```bash
   cd backend
   ```
   Установите зависимости: npm install

Запустите сервер: npm run start: dev

## Функциональность:

- Добавление новых задач

- Просмотр списка задач

- Отметка задач как выполненных

- Разделение на выполненные и невыполненные задачи

## Особенности реализации

1. **Backend**:

   - Использован NestJS для создания простого REST API
   - Реализованы два эндпоинта: GET /tasks и POST /tasks
   - Данные хранятся в памяти (для production нужно добавить базу данных)

2. **Frontend**:

   - Использован React с функциональными компонентами и хуками
   - Применена мемоизация компонентов с помощью React.memo
   - Использованы хуки useCallback и useEffect для оптимизации
   - Material-UI для UI компонентов
   - SCSS с БЭМ методологией для стилей
   - Кастомные миксины и переменные в SCSS
   - Axios для HTTP запросов
   - Обработка состояний загрузки и ошибок

3. **Архитектура**:
   - Разделение на компоненты (TaskForm, TaskList)
   - Отдельный слой для API запросов
   - Глобальные стили и переменные
